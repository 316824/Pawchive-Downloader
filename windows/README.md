# Pawchive Downloader · Windows v1.1.0（v1.2.0 待发布增强）

用于下载 Pawchive 画师主页下图片原图与帖子附件的 Windows 桌面工具。支持封面预选、按图集整理、后台运行、预约下载和进度恢复；保留明暗主题、四种界面语言、粒子光效和彩虹进度条。当前本地分支还加入了画师成长奖励柜，以及仅供发布者使用的本机记录清理工具；这些改动尚未上传 GitHub。

## 下载与首次运行

前往 [Windows v1.1.0 发布页](https://github.com/316824/Pawchive-Downloader/releases/tag/windows-v1.1.0)，推荐下载 `PawchiveDownloader-Windows-x64.zip`，解压后双击 `PawchiveDownloader.exe`。发布页也提供单独 EXE。

发布的 EXE 面向 **64 位 Windows**，已包含 Python 运行环境及依赖库，无需另外安装 Python、PySide6 或其他组件，也不会在首次运行时帮你联网安装这些依赖。分享便携包时，请保留包内的使用说明、MIT 许可证和第三方依赖许可文件。

### 设备专属邀请码

官方 v1.1.0 首次运行需要邀请码：

1. 在欢迎窗口选择界面语言，点击“复制设备码”。
2. 将设备码提供给维护者，获取仅适用于该设备的邀请码。
3. 完整粘贴邀请码，点击“验证并进入”。验证通过后即可使用工作台。

验证结果保存在当前用户的本机数据中；正常情况下，下次打开无需再次输入。设备码由本机信息生成，程序在本机核对设备绑定与数字签名，**不自动上传设备信息、邀请码或签到记录**。更换设备或重装系统导致设备码变化时，需要重新获取对应邀请码。

错误邀请码累计 **10 次**后锁定，次数跨程序重启保留。前 9 次失败后，第 10 次填写正确邀请码仍能通过；不要反复试猜。锁定后，联系维护者申请该设备的解锁码，再点击“使用解锁码”。解锁码与邀请码用途不同，解锁成功后再填写有效邀请码；已使用的解锁码不能重复使用。解锁码同样限制错误尝试，连续错误达到上限后有 24 小时冷却。

客户端只包含公开验签公钥，签发私钥与维护者签发工具不随公开源码或发行包提供。此机制用于官方发行版的设备邀请管理，无法绝对阻止传播或绕过。项目原创代码依然适用 [MIT License](../LICENSE)，允许按许可证修改和再分发，包括修改客户端的验证逻辑。

## 快速开始

1. 输入完整画师主页链接，例如 `https://pawchive.pw/fanbox/user/76050360`；也可点击粘贴按钮，或按 `Ctrl+Shift+V` 粘贴链接。
2. 点击保存位置旁的“浏览…”选择文件夹；按需勾选“保存为默认路径”。
3. 选择日期顺序和保存方式，点击“开始下载”。
4. 默认先扫描图集。在选择窗口中检查封面、标题和附件类型，取消不需要的图集，然后确认下载。
5. 下载结束后，点击状态文字右侧的“打开文件夹”查看文件。

“开始下载”在主页链接有效且已选择保存位置后启用。请输入 Pawchive 的完整画师主页链接，不能填写单个帖子链接。程序会按照网站的分页规则继续读取后续图集。

## 扫描与封面选择

- “先扫描标题并选择下载图集”默认开启；关闭后下载主页下找到的全部图集。
- 扫描窗口支持暂停、继续和结束扫描，并显示扫描页数与已找到的图集数量。“结束扫描”会完成当前处理，返回已经完整收集到的图集供选择。
- 图集默认全部选中。点击封面卡片逐个调整，彩色边框表示已选中。
- 卡片会提示帖子中的直链附件格式，如 ZIP、MP4、PSD。左上角的复选框控制整篇图集，选中后会下载其中的图片及直链附件。
- 选择窗口提供全选、全不选、美化滚动条和圆形回到顶部按钮。封面只是临时预览，实际保存的是页面提供的原图或附件。

## 保存规则与下载进度

| 选项 | 行为 |
| --- | --- |
| 日期顺序 | 从新到旧或从旧到新下载 |
| 按图集标题分别存入文件夹 | 默认开启，以帖子标题创建子文件夹 |
| 下载后按日期顺序编号重命名 | 关闭图集文件夹后可用；将本次下载的文件按发布日期从旧到新编号，保留扩展名 |
| 起始编号 | 默认从 `1` 开始，也可指定其他起始数字 |
| 保存为默认路径 | 默认关闭；开启后将当前保存位置记在本机，下次启动时使用 |

所选图集中的图片原图与直链附件会一起保存。直链附件优先使用网页提供的下载文件名，保留后缀。平铺保存时，跨图集的同名直链附件会加上图集标题区分，同一图集内的重名文件添加序号；已有文件不会被直接覆盖。开启编号后，本次下载的文件按发布日期编号整理。

彩虹进度条按当前文件实际收到的数据更新；网站没有返回文件总大小时显示不定进度。工作台同时显示传输量、已保存文件数和当前图集序号 `(当前/总数)`，便于区分单文件进度与整个下载任务。

程序会检查常见无效响应，处理连接中断并有限重试。ZIP、MP4、PSD 等直链文件之间会适当等待，减少过于密集的请求；图片按正常流程下载。类型检查不等同于完整内容校验，网站限制、原文件损坏或链接失效仍可能导致失败。

若连接持续失败，任务会停止并记录原因。按标题分文件夹时，会清理本次任务新建、尚未完成的图集文件；此前完成的图集和原有目录中的其他文件保留。平铺保存没有独立的“未完成图集文件夹”，不会按整目录清理。

## 后台运行与正常退出

点击窗口右上角 `×` 后，可选择：

- **留在后台**：隐藏工作台，继续当前扫描或下载，并等待已登记的日程。程序图标保留在任务栏右侧的系统托盘中，可能位于折叠的图标区。
- **保存并退出**：停止当前下载、保存恢复记录，再退出软件；尚未完成的分片留待下次使用。没有下载任务时正常退出。
- **取消**：返回工作台。

点击托盘图标可恢复工作台，右键菜单可打开下载日程、签到日历或退出软件。后台下载完成时可显示系统通知。若系统托盘不可用，“留在后台”会禁用。

再次打开 EXE 会交给当前用户已经运行的实例处理，避免重复窗口和重复执行。后台仍是正在运行的软件，会使用少量内存；它不让电脑保持唤醒。

## 继续上次下载

下载未完成时，使用正常的“保存并退出”。程序会记录画师、保存位置、排序方式、选中图集、已经完成的文件和未完成分片。下次启动时发现可恢复任务，会询问：

| 操作 | 结果 |
| --- | --- |
| 继续下载 | 校验已记录文件，跳过可确认完整的部分，继续未完成任务 |
| 稍后再说 | 保留进度，本次先不恢复 |
| 放弃这份进度 | 只移除该任务的恢复记录与其临时分片；已经保存的文件保留 |

服务器支持且正确响应 Range 请求时，未完成文件会从现有分片继续；不支持或校验不一致时，会重新下载该文件，避免错误拼接。程序不会把普通 `.part` 分片当作已完成图片。

封面缓存与恢复记录分开管理：扫帚按钮和正常退出清理封面缓存，**不会清除待续传任务**。待恢复分片会占用原保存盘空间；决定不再继续时，请在恢复提示中选择放弃。恢复需要保留原保存文件夹；外置盘、网络盘等也需仍然可访问。

正常退出保留进度的行为，与主动停止任务或网络持续失败时清理当前未完成图集的行为不同。强制结束进程、断电或手动修改记录不属于正常退出流程，无法保证最后一段进度及时保存。

## 下载日程

### 添加与管理

1. 点击窗口顶部的**工具齿轮 → 下载日程**，托盘右键菜单也可进入。
2. 填写完整画师主页链接和保存位置。
3. 选择未来的执行日期、时间、日期顺序，以及分文件夹或编号规则。
4. 点击“添加日程”。列表中会显示执行时间、状态、链接和保存位置。
5. 不再需要时，选中列表中的预约并点击“取消所选日程”。执行中的任务需先在工作台停止。

这是**单次预约**，不是每日重复计划。每个预约保存创建时的链接、目录和下载规则，后来修改主界面不会改变已经登记的预约；需要调整时，取消后重新添加。

最多保留 **10 个活动日程**，包括已预约、排队中、执行中和等待续传。已完成、已取消、已错过和失败的记录不占活动名额。等待续传的日程不会自己重新开始，可在启动时恢复，或取消后释放名额。

定时执行会自动下载该画师的**全部图集及附件**，不弹出封面预选窗口。手动下载或另一预约尚未结束时，新到期的预约进入队列，之后逐项执行，不会同时开启多项下载任务。

### 什么情况下能按时执行

| 电脑与程序状态 | 行为 |
| --- | --- |
| 软件在工作台或托盘后台，当前用户已登录 | 到时开始；忙碌时排队 |
| 软件已经正常退出，电脑开机且当前用户仍已登录 | Windows 计划任务启动软件并执行预约 |
| 当前用户已登录但屏幕锁定 | 可以执行，仍需网络与保存位置可用 |
| 电脑关机、睡眠、休眠或该用户已注销 | 不唤醒、不补跑错过的预约 |

预约使用 Windows 自带计划任务，以当前用户权限运行，正常情况下**不需要管理员权限，也不保存 Windows 登录密码**。Windows 计划任务服务必须可用；受单位策略、权限或安全软件限制时，添加日程会显示错误，不会伪装成预约成功。电脑时间与时区应正确，预约以创建时选定的具体时刻执行。

只对正常的短暂启动延迟保留约两分钟容差，不会在关机后重新开机时集中补下载。软件已经运行且任务排队时，等待其他任务结束不受这段启动容差限制。

### 为什么移动 EXE 后预约还能运行

创建日程时，发行版会在 `%LOCALAPPDATA%\PawchiveDownloader\bin` 保存一份经过校验的稳定 EXE 副本，当前版本约 **45 MB**。Windows 计划任务指向这份副本，因此移动原下载位置中的 EXE 不影响已经登记的日程，也不会为每个日程再复制一份。

请保留这份运行副本和预约保存目录。删除本机数据、手动删除计划任务或移动源码运行环境都会使预约失效。源码模式使用创建预约时的 Python 与脚本绝对路径，不另外复制解释器或源码；调整位置后应取消并重新创建预约。更新版本后运行新 EXE，未来预约所用的稳定副本会随之核对更新。

## 签到日历

打开**工具齿轮 → 签到日历**，点击“记录今天”，当天即可留下一个标记。日历可以浏览其他月份，查看累计与连续天数，以及阶段性的欢迎寄语。日历下方还会显示画师等级、徽章、画师图鉴、成就彩蛋和主题皮肤选择器。

每天按本机日期只能记录一次，不支持补签或预约未来签到。累计足迹长期保留；中断不会扣分、移除收藏或限制下载功能。签到不涉及付费、排行或上传记录，仅为愿意回来时留一份轻松的反馈。

### 画师等级、徽章与图鉴

奖励完全由本机状态派生，不需要账号或网络。每天按当前 Windows 本地日期只能签到一次；不支持补签或预约未来签到。错过一天只会让当前连续天数归零，历史最高连续纪录和已经解锁的内容不会回退。

| 进度 | 解锁内容 | 说明 |
| --- | --- | --- |
| 累计签到 0 / 7 / 30 / 100 / 365 天 | 初见画师、灵感学徒、连载画师、资深画师、传说画师 | 等级按累计天数提升，签到窗口显示距离下一级的进度 |
| 累计签到 1 天 | 第一束灵感徽章、第一页·初见图鉴、欢迎回来成就 | 第一次成功签到即获得 |
| 历史最高连续 7 天 | 七日连星徽章、七日手记图鉴、连星初成成就 | 断签后仍然保留 |
| 历史最高连续 30 天 | 月度不缺席徽章、海蓝档案图鉴、月度连载成就 | 同时解锁海蓝潮汐与霓虹赛博两套主题皮肤 |
| 历史最高连续 100 天 | 百日长卷徽章 | 长期连续签到彩蛋 |
| 累计签到 100 天 | 百次回访徽章 | 与连续 100 天分开计算 |
| 成功下载 1 次 | 第一份档案成就 | 仅在下载任务成功完成后计入 |
| 成功保存 100 / 500 个文件 | 百图收藏家、大档案室图鉴 | 下载计数保存在本机，用于展示柜解锁 |

签到窗口的三个分页分别展示**徽章**、**画师图鉴**和**成就彩蛋**。未解锁卡片会显示条件，已经获得的内容会永久保留；它们只是本机可见的纪念，不改变邀请码、下载权限或网站访问能力。

### 主题皮肤

连续签到达到 30 天后，签到窗口的“主题皮肤”选择器会解锁**海蓝潮汐**与**霓虹赛博**。选择后会立即改变工作台的配色，并写入本机设置；明暗滑钮仍可独立切换。错过一天不会收回已经解锁的皮肤或徽章，只有当前连续天数会重新计算。下载会在本机累计保存的文件数，用于图鉴和成就解锁，不会上传文件名、链接或统计。

## 外观与辅助功能

- **工作台布局**：清晰的功能分区、流程状态、文件与图集统计，窗口可拖动调整或最大化。
- **四种语言**：简体中文、繁體中文、English、日本語；首次邀请窗口及日程、签到、后台退出和恢复提示也随语言切换。
- **明暗主题**：太阳／月亮滑钮切换，缓入缓出动画与圆角外观保留。
- **交互光效**：紫色按钮高亮、鼠标粒子、复选框渐变扩散和彩虹进度条；复选框效果由上层绘制，减少边缘裁切。
- **快捷辅助**：`Ctrl+Shift+V` 粘贴链接、`Ctrl+L` 显示／收起日志、日志一键复制、下载完成后打开文件夹。没有开始下载的键盘快捷键。
- **缓存清理**：顶部扫帚按钮在空闲时清理临时预览缓存；工作期间禁用，避免影响正在使用的封面或任务。
- **署名彩蛋**：底部彩色署名悬停时渐渐加速；点击可见单字弹动和烟花，粒子自然淡出。

## 本机数据放在哪里

| 数据 | 保存与清理方式 |
| --- | --- |
| 语言、日程、签到与激活记录 | 当前用户 `%LOCALAPPDATA%\PawchiveDownloader` 中的小型本机数据库，退出后保留 |
| 默认保存路径 | 当前用户注册表 `HKEY_CURRENT_USER\Software\PawchiveTools\PawchiveDownloader`，由 Qt 设置接口维护 |
| 预约启动副本 | 同目录 `bin` 子文件夹，约 45 MB；用于软件关闭后的定时启动 |
| 封面预览 | 每次运行的临时缓存；空闲时可手动清理，正常退出自动清理 |
| 下载恢复记录 | 本机数据库中保留，直至完成或放弃 |
| 未完成文件分片 | 用户指定保存位置中的本任务 `.part` 文件，继续时复用，放弃时定向清理 |
| 已完成图片和附件 | 用户指定的保存位置，不属于缓存，不被扫帚按钮或放弃进度删除 |

本机数据库会包含画师链接与保存路径等个人使用信息，请勿上传仓库或随意公开。需要彻底移除软件数据时，应先取消仍在等待的预约，再处理本机数据；删除设置可能导致需要重新激活。

### 发布者本机记录清理工具

`publisher_cleanup.ps1` 与 `PawchivePublisherCleanup.cmd` 只供发布者在打包或交付前使用，不应放入公开发行包。本次整理不再生成“干净版压缩包”；发布者先运行清理工具，再单独分发 EXE 和说明文件。它会：

1. 校验当前 Windows 用户的 SID，只定位该用户创建的 `PawchiveDownloader-<用户哈希>-<日程 ID>` 计划任务。
2. 删除这些计划任务，避免后台预约继续启动旧副本。
3. 删除 `%LOCALAPPDATA%\PawchiveDownloader`，其中包括签到、等级、徽章、皮肤、激活、语言、日程、下载断点、锁文件、错误日志和 `bin` 中的定时启动副本。
4. 只有显式添加 `-RemoveRegistry` 时，才删除 `HKCU\Software\PawchiveTools\PawchiveDownloader` 的默认保存路径设置。

工具默认要求手动输入 `CLEAN`，并且会在发现主程序或托盘仍运行时中止。它绝不会删除用户下载目录、已完成图片、普通 `.part` 文件或邀请码签发私钥。推荐先预览：

```powershell
cd windows
.\PawchivePublisherCleanup.cmd -Preview
.\PawchivePublisherCleanup.cmd -RemoveRegistry
```

在已经人工确认、需要无人值守执行时才使用 `publisher_cleanup.ps1 -RemoveRegistry -Force`；`-WhatIf` 也可用于 PowerShell 原生预览。清理之后如果发布者还要继续使用软件，需要重新输入该设备的有效邀请码。

## 版本说明与已知问题

## 从源码运行

先安装所选 PySide6 版本支持的 **64 位 Python**。本次 Windows 构建使用 Python 3.14；其他 Python 版本需自行验证。在仓库根目录打开 PowerShell，然后执行：

```powershell
cd windows
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe download_pawchive_images.py
```

`requirements.txt` 固定直接运行依赖：

- `PySide6-Essentials==6.12.0`
- `requests==2.34.2`
- `beautifulsoup4==4.15.0`
- `cryptography==50.0.2`

PySide6-Essentials 已提供程序使用的 Qt 核心、界面和本机通信模块，无需额外安装 Addons、WebEngine 或 PDF 组件。Cryptography 用于设备邀请的数字签名验证。请保留同目录的其他 Python 模块、`1.ico` 和 `activation_public.json`；不能仅复制主脚本运行。源码默认使用相同的设备邀请流程。

运行离线功能检查：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用隔离的临时数据，计划任务单元检查使用替代调用，不会创建真实用户预约或联网下载。真实 Windows 定时启动需要单独做受控实机验证。更新依赖或修改代码后，应重新检查界面、文件处理和下载行为。

## 自行打包 EXE

在干净的 Windows 虚拟环境中构建。在仓库根目录打开 PowerShell：

```powershell
cd windows
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build_release.py
```

`requirements-build.txt` 包含运行依赖及固定的 PyInstaller、构建 hooks 和 PE 文件检查工具。`build_release.py` 配合 `PawchiveDownloader.spec`：

- 使用最小化搜索路径，减少混入其他软件目录中的同名动态库。
- 收集实际使用的 Qt 模块、必要插件和运行依赖，包括邀请验证依赖。
- 内嵌 `1.ico` 与公开验签公钥，保留 EXE、任务栏和相关窗口的图标。
- 核查 ICU 和内嵌二进制依赖，对生成 EXE 执行离线启动自检；失败时停止构建。

成功后文件位于 `dist/PawchiveDownloader.exe`，同目录 `startup-check.json` 记录启动自检结果。建议使用上述入口，不要用旧版通用打包命令绕过依赖检查。用户运行发行版不需要 `build` 文件夹或 `.spec` 文件，但分享时应附上项目与第三方许可说明。

固定依赖与构建配置用于减少环境差异，不保证不同机器生成逐字节相同的 EXE。Fork 维护者应自行管理签发密钥与公开验签配置，禁止将私钥提交到仓库或打入 EXE。
