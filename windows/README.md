# Pawchive Downloader for Windows · v1.2.2

Pawchive Downloader 是面向 Windows 用户的画师图集下载工具，支持批量选择图集、断点续传、下载队列、拖拽调整优先级、托盘后台运行和本地成就系统。

v1.2.2 重点改善了后台下载提示、任务栏反馈和中断恢复体验：

- 窗口最小化、隐藏到托盘或切换到其它程序后，下载完成仍会弹出托盘通知。
- Windows 任务栏显示实时下载进度。
- 主窗口和托盘使用统一的圆角应用图标。
- 软件重启后会重新扫描未完成图集，恢复任务封面、附件数量和剩余文件总数。
- 恢复下载时，任务概览进度条按剩余队列的总文件数计算。
- 图片下载最多五路并发；ZIP、视频和其它非图片附件保持单路下载。

## 系统要求

- Windows 10 或更高版本
- 64 位 Windows
- 能够访问 Pawchive 的网络环境
- 对保存目录拥有写入权限

发布版是独立 EXE，不要求安装 Python。建议将 EXE 放在普通文件夹中运行，不要放在只读系统目录。

## 安装与首次验证

从 GitHub Releases 下载 PawchiveDownloader.exe，双击启动。

首次运行需要完成设备验证：

1. 点击“复制设备码”。
2. 将设备码发送给软件发布者。
3. 将收到的邀请码粘贴到输入框。
4. 点击“验证并进入”。

复制按钮会显示按下缩放和回弹动画，并短暂变为“已复制”。验证成功后，授权信息会保存在本机，后续启动无需再次输入。

设备码和邀请码属于本机授权信息，不要发布到公开 Issue、聊天群或截图中。

## 开始下载

在“画师主页链接”输入完整的 Pawchive 画师主页，例如：

    https://pawchive.pw/fanbox/user/3439325

选择保存目录，然后点击“开始下载”。

可用选项包括：

- 按图集标题分别保存到独立文件夹
- 按发布日期从新到旧或从旧到新排序
- 扫描标题后手动选择图集
- 平铺保存并按日期顺序编号
- 自定义编号起始值

图集标题、封面、附件数量和文件类型会在下载前显示，便于确认任务范围。

## 粘贴、拖拽和剪贴板

支持以下输入方式：

- 将画师主页链接粘贴到输入框
- 将画师主页链接拖入窗口
- 将帖子链接粘贴到输入框
- 将帖子链接拖入窗口

如果输入的是帖子链接，软件会提取所属画师，并询问你是扫描该画师的图集后选择批量下载，还是只下载当前帖子。

软件在后台运行时也会检测剪贴板中的 Pawchive 画师链接。同一个链接在一次启动期间只提醒一次，通知之间有冷却时间，避免重复弹窗。

## 下载队列

批量下载时，右侧任务队列会显示图集封面、标题、当前状态、单项进度、文件数量和错误提示。

可以对任务执行：

- 暂停
- 继续
- 取消
- 重试
- 移到最高优先级

队列支持拖动单个任务，也支持框选多个任务后一起调整优先级。图片任务最多五路并发；检测到 ZIP、视频、PSD 等非图片附件时，软件会使用单任务下载。

失败任务会保留在队列中并让位给后续任务。点击重试后，该任务会回到最高优先级。

## 回收站

取消的下载会进入下载回收站，默认保留约 24 小时。项目包含封面、标题、原帖子链接和恢复下载按钮。

点击右侧下载队列标题栏旁的回收站入口即可查看、恢复或删除项目。

## 关闭窗口、托盘和任务栏

点击窗口右上角 X 时，软件默认隐藏到托盘，下载会继续进行。

- 托盘图标右键菜单可以重新打开窗口。
- 只有选择“退出软件”才会完全结束程序。
- 窗口最小化或隐藏后，下载完成仍会弹出托盘通知。
- Windows 任务栏图标下方会显示当前下载进度。
- 任务栏和托盘使用圆角 Pawchive 图标。

如果系统关闭了应用通知，请在 Windows 设置、系统、通知中允许 Pawchive Downloader 显示通知。

## 中断恢复与断点续传

如果下载过程中退出软件、关闭窗口或电脑重启：

1. 已完成且校验通过的文件会保留。
2. 未完成文件会保留受软件管理的临时断点。
3. 下次启动时软件会提示恢复任务。
4. 恢复前会重新扫描剩余图集。
5. 队列会重新加载封面、标题、附件数量和文件总数。
6. 任务概览会按剩余队列重新计算总进度。

恢复时不会重复下载已经验证完成的文件。恢复扫描失败时，checkpoint 会保留，方便稍后再次尝试。

## 签到、徽章和画师档案卡

“签到日历”提供累计签到、连续签到、徽章、画师图鉴、Steam 风格成就和主题皮肤。

连续签到 7 天可解锁签到徽章；连续签到 30 天可解锁主题皮肤。完成指定画师下载成就后，会生成画师档案卡，包含画师头像、下载统计和成就信息。

这些统计保存在本机，不会自动上传。

## 自定义背景和竖屏模式

背景编辑器支持 JPG、JPEG、PNG 和 WEBP。你可以为工作台、扫描、选择图集和其它页面分别设置背景。

编辑时可以滚轮缩放、拖拽平移、调整裁剪框、选择原图起始坐标和设置深色遮罩透明度。

软件会限制图片格式、尺寸和像素数量，并使用缩略图缓存，避免多个页面同时加载原图。

主界面的手机图标用于切换竖屏模式；电脑图标用于恢复普通窗口模式。竖屏模式会自动堆叠控件并保持背景比例。

## 缓存清理

主界面的扫帚按钮可以清理扫描临时目录、未使用的背景缩略图、未引用的头像缓存和中断后的临时缓存。

清理功能不会删除已完成下载、用户保存目录或有效的断点续传数据。

## 本地数据位置

用户数据默认保存在：

    %LOCALAPPDATA%\PawchiveDownloader

其中可能包含签到和成就、下载 checkpoint、下载回收站、自定义背景元数据、头像和缩略图缓存以及本地设置。

这些数据只保存在当前 Windows 用户账户中，不会自动同步到其它设备。

## 常见问题

### 为什么关闭窗口后程序还在运行？

这是默认行为。右键点击托盘图标，选择“退出软件”才会完全退出。

### 为什么恢复下载前会重新扫描？

软件需要重新确认剩余图集、封面和附件数量，才能正确显示剩余总进度，并避免使用已经失效的临时封面。

### 为什么任务栏没有进度？

请确认使用的是 Windows 10 或更高版本，并且运行的是 v1.2.2 或更新版本。某些远程桌面环境、精简系统或任务栏增强工具可能不显示第三方任务栏进度。

### 下载失败怎么办？

先查看任务队列中的错误信息：

1. 点击“继续”或“重试”。
2. 检查网络和保存目录权限。
3. 如果网站暂时限流，等待一段时间后再重试。
4. 如果失败任务长期无法完成，请提交错误文本和软件版本。

不要提交设备码、邀请码、Cookie、数据库文件或包含本机路径的截图。
