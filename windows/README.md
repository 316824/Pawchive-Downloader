# Pawchive Downloader for Windows · v1.3

Pawchive Downloader 可以扫描 Pawchive 画师主页、展示图集封面、选择需要保存的图片或附件，并将内容整理到本地。Windows 版提供可恢复的下载队列、托盘后台运行、签到主题、自定义背景、画师档案卡和更新订阅。

- [项目首页与平台选择](../README.md)
- [Windows 版本发布页](https://github.com/316824/Pawchive-Downloader/releases)
- [Android 使用说明与 APK 下载方法](../android/README.md)

本页介绍 v1.3 的功能与使用方法。实际可下载的 EXE 版本以发布页中的附件为准。

## v1.3 更新内容

本次更新保留原有下载和主题功能，将以下新增功能与体验修复合并为一次大更新：

- **今日画师推荐**：签到页按当天日期固定抽取最多 10 个不重复热门图集，支持封面预览、高清单图查看和单独下载附件。
- **画师档案与订阅**：记录画师头像、名称、ID 和下载统计，按每页最多 20 位展示；后台检查新图集，用加载状态和红点提示更新。
- **更完整的中断恢复**：保留保存目录、日期方向、标题文件夹、图片编号和内容选择；重新扫描剩余图集时展示实时进度，并补全封面与标题。
- **恢复后的图片编号**：完成下载后按图片修改时间递增整理，从 1 开始编号；重启恢复也沿用原任务选项，视频和其它附件不受影响。
- **独立选择下载内容**：工作台可统一选择图片与附件、仅图片、仅直链附件；预选窗口还能为每个图集单独设置。
- **失败任务集中处理**：错误图集在成功前始终置顶，失败状态显示红字；独立“失败任务”窗口支持逐项和全部重试，状态与主队列同步。
- **暂停与继续**：修复单项暂停后继续的问题，增加“全部暂停 / 全部继续”切换按钮；自动重试会冷却并重新建立下载连接。
- **更平稳的队列操作**：大批量任务分批显示，准备任务和最终编号放到后台处理；点击重试时保持当前滚动位置。
- **窗口与背景体验**：修复背景裁剪效果预览，全屏或最大化与竖屏互斥；下载中从托盘退出时需要确认。
- **完成与后台反馈**：完成提示右侧可直接打开下载目录，窗口最小化或隐藏到托盘后仍有完成通知，任务栏显示总体下载进度。
- **临时文件管理**：预览关闭后释放临时图片，每次启动清理超过 24 小时的软件临时目录，正在使用的预览和有效下载断点受到保护。
- **软件版本提示**：启动时在后台检查 GitHub 正式发布版本，页脚红点入口展示更新说明，支持前往下载、稍后查看与忽略该版本。
- **档案数据迁移**：用迁移代码备份或恢复画师资料、成就统计和订阅时间记录，重复画师自动合并。

## 系统要求与首次启动

- Windows 10 或更高版本，64 位系统。
- 可以访问 Pawchive 的网络环境。
- 对所选下载目录有写入权限。

发布版为独立 EXE，无需安装 Python。从 [Releases](https://github.com/316824/Pawchive-Downloader/releases) 下载 Windows 附件，放入有写入权限的普通文件夹后双击运行。

首次启动需要完成设备验证：

1. 点击“复制设备码”。按钮会缩放回弹，并短暂显示“已复制”。
2. 将设备码提供给软件发布者，获取对应邀请码。
3. 粘贴邀请码，点击“验证并进入”。
4. 验证成功后，后续启动无需重复输入。

## 开始一次下载

1. 在“画师主页”输入完整链接，例如：

   ```text
   https://pawchive.pw/fanbox/user/3439325
   ```

2. 点击“浏览…”选择保存目录。需要以后沿用时，勾选“保存为默认路径”。
3. 选择日期方向：从新到旧或从旧到新。
4. 按需要勾选“按图集标题分别存入文件夹”“先扫描标题并选择下载图集”“下载后按日期顺序编号重命名”。
5. 选择下载内容：图片与附件、仅图片，或仅直链附件。
6. 点击“开始下载”。开启预选后，先确认图集再开始传输。
7. 等待下载及编号整理结束，点击完成提示右侧的“打开文件夹”查看文件。

预选窗口展示图集封面、标题、图片数量、附件数量和格式。除了选择下载哪些图集，还可以为每个图集单独指定“图片与附件”“仅图片”或“仅直链附件”。

“仅图片”读取帖子中的图片流；“仅直链附件”读取帖子提供的附件链接。选择依据是链接类别，而不只是文件后缀。例如，通过附件链接提供的图片也属于附件下载选项。

## 保存方式与图片编号

“按图集标题分别存入文件夹”和“下载后按日期顺序编号重命名”可以独立选择。

| 设置 | 图片保存位置 | 附件保存位置 | 启用图片编号时 |
| --- | --- | --- | --- |
| 按图集标题保存 | 所选目录 / 图集标题 | 图集标题 / 附件文件 | 每个图集的图片分别从 `1` 开始 |
| 不按图集标题保存 | 所选目录 / 图片文件 | 视频文件 / 图集标题；其它文件 / 图集标题 | 所有图片统一从 `1` 开始 |

关闭标题文件夹时，图片不因 JPG、PNG 或 WEBP 等后缀不同而分散到多个目录；视频、压缩包、PSD、CLIP 等其它内容仍按图集标题分组，便于辨认来源。

启用编号后，软件按对应目录内图片的修改时间递增排列，生成 `1.jpg`、`2.png` 等连续编号，保留图片实际后缀。编号从 1 开始，不提供修改起始编号的选项。视频、压缩文件、PSD、CLIP 等不参加图片编号。

编号在下载结束后统一整理。如果状态显示“正在整理图片编号…”，请等待完成提示。中途退出后再次恢复，也会把上次已保存和本次补下的图片一起纳入整理。

## 下载队列与总进度

右侧队列显示每个图集的缩略图、标题、文件数量、状态和进度；任务概览显示队列总体进度，当前文件的大小与速度另行展示。

每个项目可以暂停、继续、取消、重试或提升优先级。支持拖动单项，也支持在空白区域框选多个项目后一起调整优先级。

图片最多五路并发。ZIP、视频、PSD 等直链附件保持单路下载，减少触发网站限流的风险。

### 暂停与继续

- 点击图集上的“暂停”，软件保留断点，并继续处理其它可运行任务。
- 点击该图集的“继续”，它会从断点重新排队；暂停过程尚未结束时的继续操作也会保留。
- 点击队列工具区的“全部暂停”，可暂停运行中和等待中的任务。
- 同一按钮随后变为“全部继续”，再次点击恢复已暂停任务。

### 失败与重试

出现过下载错误的图集会一直保留在队列顶部，直到成功完成；重试期间或再次失败时也不会被普通任务、已完成任务盖住。“下载失败”显示为红色，缩略图上有错误提示。

点击“失败任务”打开集中处理窗口。窗口显示与主队列相同的标题、封面、状态和进度，可以逐项重试，也可以点击“全部重试”。两个窗口共享同一任务，不会重复提交两次下载。

重试操作会保持当前滚动位置。其余队列完成后，软件还会经过冷却自动重试失败图集，最多三轮；重试会重新建立下载连接，并检查已有临时数据。远程文件已删除或网站持续拒绝访问时，可查看错误信息后稍后再试。

## 中断恢复与断点续传

点击窗口右上角 `×` 只是隐藏到托盘，任务会继续。若从托盘退出、电脑重启或软件异常关闭，未完成任务会保留可恢复记录。

再次启动后，“继续上次的旅程？”会在主窗口中央出现：

1. 选择继续。
2. 软件恢复原来的保存目录、日期方向、标题文件夹、图片编号和下载内容设置。
3. 先重新扫描尚未完成的图集；扫描窗口显示实时页数、图集数量。
4. 队列重新加载封面、标题、附件数量和文件总数。
5. 校验已经保存的文件，再继续处理剩余内容。
6. 下载结束后，按原先选项完成图片编号。

恢复后的任务概览以本次剩余队列的文件总量计算进度。重新扫描失败时，恢复记录会保留，方便稍后继续。

## 取消下载与回收站

取消的图集暂存于下载回收站，默认保留约 24 小时。项目保留封面、标题、原始链接和恢复入口。软件关闭期间也会在下次启动时检查过期状态。

点击队列标题栏的回收站图标，可以查看、恢复或删除取消的项目。

## 粘贴、拖拽与剪贴板哨兵

可以把画师主页或帖子链接粘贴进输入框，也可以拖入主窗口。

输入帖子链接时，软件会识别所属画师，并询问是扫描画师的全部图集后选择下载，还是只下载当前帖子。

软件在后台时可以检测剪贴板中的 Pawchive 画师链接，托盘提示“主人，检测到新图集，要直接开始下载吗？”。点击通知即可回到软件处理。同一链接在一次启动期间只提示一次，通知之间有冷却时间。

## 托盘运行与任务栏反馈

点击主窗口右上角的 `×` 会隐藏到托盘，下载继续运行。窗口最小化或隐藏后，下载完成都会弹出“主人，你的图集下载好了哦～”。下载期间，Windows 任务栏图标显示总体进度；任务栏和托盘使用圆角应用图标。

需要彻底退出时，右键点击托盘图标，选择“退出软件”。有正在进行的下载时，会询问“检测到当前下载任务正在进行，是否继续退出？”。取消可继续下载，确认退出后可以在下次启动恢复。

如果没有收到通知，可以在 Windows“设置 → 系统 → 通知”中检查是否允许应用通知。

## 下载日程

在工具菜单或托盘右键菜单中打开“下载日程”：

1. 输入画师主页并选择保存目录。
2. 选择执行日期和时间、日期方向、标题文件夹及图片编号选项。
3. 点击“添加日程”，在列表中查看执行状态。取消预约时，选中项目后点击取消按钮。

待执行、排队、运行中或暂停的日程合计最多 10 个。日程到时会下载该画师的全部图集，不弹出预选；遇到其它下载正在运行时排队处理。电脑必须保持开机并登录 Windows，关机期间错过的时间不会补跑。定时下载中断后仍可通过恢复提示继续。

## 软件更新提示

启动后，软件会在后台向本项目 GitHub 仓库检查最新正式发布版本，不影响现有操作。发现新版时，主窗口左下方的版本号旁会出现红色“● 发现新版本”按钮。点击可打开更新说明窗口，滚动阅读 Markdown 版本日志。

- **前往下载**：在浏览器打开该版本的官方 Release 页面，再选择 Windows EXE 附件。
- **稍后再说**：关闭说明，保留页脚提醒，方便稍后查看。
- **忽略该版本**：把选择保存在本机，该版本不再提示；以后出现更高版本仍会提醒。

发布者未填写版本说明时会显示中文提示。网络超时、GitHub 暂时不可用或没有正式新版时，不弹出错误提示，也不会阻碍下载；需要时可直接访问 [Releases](https://github.com/316824/Pawchive-Downloader/releases)。替换 EXE 前，请先完成当前任务或安全退出软件。

## 签到、徽章与主题

从工具菜单打开“签到日历”，每天记录一次签到：

- 连续签到 7 天解锁签到徽章。
- 连续签到 30 天解锁海蓝、赛博朋克等主题皮肤。
- 累计签到与下载进度用于解锁画师图鉴、成就和其它界面奖励。

已解锁主题可以随时切换。签到和奖励记录保存在本机，不需要登录账号，也不影响下载功能。

### 今日画师推荐

在签到页点击“今日画师推荐”。软件从 Pawchive 当天热门页的第一页按排名加权抽取最多 10 个不重复图集，并用当天日期固定结果。同一天重复打开仍是同一组推荐，第二天再更新。

卡片展示封面和标题，悬停时显示画师 ID。点击卡片进入预览：先加载轻量缩略图，点开某张图时再加载高清图。预览底部可以：

- 下载当前图集，并通过工作台确认保存路径、标题文件夹和图片编号选项。
- 搜寻该画师的全部图集，进入正常的扫描预选流程。
- 单独下载直链附件；无法直接识别的外部链接交由浏览器打开确认。

热门页请求超时会显示“今日热搜数据流中断，请稍后再试”。关闭预览会释放对应临时图片，正在查看的图片不会被扫帚清理功能移除。

### 画师档案卡

通过画师主页完成下载后，会记录画师头像、名称、ID 和下载统计；同一画师只保留一张档案。每页最多显示 20 位，支持翻页、添加和删除。

完成同一画师 1、5、10、25 个图集后会逐步提升本地成就，25 个图集达到最高阶段。点击主界面顶部的 `✦` 打开档案卡柜，点击画师可回填主页并进入扫描选择流程。

名字暂时无法获取时显示“Unknown Artist”，头像不可用时显示应用默认图标，仍可使用对应主页。

### 画师更新订阅

从工具菜单打开“画师更新订阅”，输入画师主页链接或数字 ID 后添加。新订阅第一次只建立当前最新图集的基线，不立即产生更新提醒。

此后每次启动，软件在后台检查订阅画师，最多同时请求三位，并在后续请求间随机等待 1～3 秒。检查期间显示加载状态，发现比基线更新的图集后显示红点；打开对应画师可以查看更新并选择下载。删除画师后，该画师不再触发提醒。

时间比较使用解析后的时间戳，避免日期补零或时区差异影响更新判断。

### 画师档案数据迁移

换电脑或需要备份画师记录时，从顶部 `✦` 打开档案卡柜，点击“数据迁移”。

**导出：** 在“导出 / 复制”页点击“复制迁移代码”，将以 `PAWCHIVE_V1:` 开头的完整文本自行保存。不要截断、删改其中内容。

**恢复：** 在另一台 Windows 电脑完成首次启动验证后，进入相同窗口的“输入恢复”页，粘贴代码并点击“恢复画师数据”。窗口会报告新增与更新的数量，档案卡及订阅状态随之刷新。

可以迁移的内容包括：

- 画师主页、名称和 ID。
- 已完成图集数、已保存文件数和对应画师的成就进度。
- 最近下载时间、订阅基线与最新检查记录。

单次最多迁移 1000 位画师。相同画师自动合并，保留较新的时间和较高的统计值；反复恢复相同代码不会重复累计数量，也不会删除本机其它画师。无效、缺失或受损的代码会显示“无效迁移代码，请完整复制后重试”，原有记录不变。

迁移代码不包含已下载内容、续传断点、日程、签到、主题、背景、设备码、邀请码、登录信息或本机文件路径。头像缓存也不会复制，无法显示头像时使用默认图标。代码包含画师档案和订阅信息，适合自行备份保管。

## 自定义背景与窗口模式

背景编辑器支持 JPG、JPEG、PNG、WEBP，可以分别为工作台、签到、扫描、选择图集等页面设置图片。

- 根据目标窗口实际尺寸建立初始裁剪比例。
- 用滚轮缩放、拖拽平移并调整裁剪框；右下角提供较大的缩放操作区域。
- 裁剪框推到边缘后保持大小，避免拉回时意外缩小。
- 实时预览裁剪方案在窗口中的实际效果，调整遮罩透明度以保证文字可读。
- 切换自定义背景、签到主题或日夜主题。

图片格式、文件大小和像素尺寸均有限制，页面使用缩略图缓存，避免同时保留多个原始大图。

主界面手机图标可切换竖屏模式，控件自动改为上下排列；电脑图标恢复普通窗口。全屏或最大化时不能进入竖屏，竖屏时也不能全屏或最大化。需要切换时，先回到普通窗口。

## 缓存清理与本地数据

主界面扫帚按钮清理应用自己的扫描缓存、未使用背景、未引用头像和已关闭预览的临时图片。每次启动还会清理超过 24 小时的应用临时目录，减少异常退出后的孤儿文件。

清理保留正在使用的预览、有效背景、下载恢复记录和受管理的 `.part` 断点文件，也不会删除已完成下载。不要手动删除有效 `.part` 文件，否则对应文件可能需要重新下载。

本地数据默认保存在：

```text
%LOCALAPPDATA%\PawchiveDownloader
```

数据包括签到、成就、下载恢复信息、回收站、背景设置、档案卡和订阅基线，不会自动同步到其它电脑。下载内容写入你选择的保存目录。

## 界面与运行日志

右上角语言菜单提供简体中文、繁体中文、English 和日本語。日夜开关切换亮色与暗色，签到页中可以选择已解锁的主题。

顶部日志按钮与 `Ctrl+L` 都可以收起或展开日志区。日志区右上角的复制按钮可以复制任务记录和错误文字；`Ctrl+Shift+V` 可粘贴链接到工作台。反馈问题时，请先遮去日志中的个人信息。

软件版本检查只向 GitHub 请求本项目的公开发布信息，不携带设备码、邀请码、画师订阅或下载记录。

## 常见问题

### 为什么有些文件没有下载？

先检查是否选择了“仅图片”或“仅直链附件”。需要全部内容时选择“图片与附件”。再查看队列顶部的红色失败项目，或打开“失败任务”集中重试。

### 暂停后怎样恢复？

点击该图集的“继续”，或使用队列工具区的“全部继续”。暂停操作正在收尾时，继续请求也会保留，线程停止后从断点重新运行。

### 为什么图片暂时没有编号？

编号在完整下载结束后统一整理。请先继续暂停项，处理失败项，并等待“正在整理图片编号…”结束。恢复任务沿用原编号设置，无需重新开启。

### 为什么恢复前要重新扫描？

软件需要重新确认未完成图集的链接、封面和文件数量，才能准确展示剩余总进度。已经验证完成的文件会保留。

### 为什么任务栏看不到进度？

请确认当前有下载任务，并使用标准 Windows 任务栏。远程桌面、精简系统或部分任务栏增强工具可能不支持第三方进度显示；主界面仍可查看总体进度。

### 换电脑后怎样保留画师记录？

在原电脑使用“画师档案卡 → 数据迁移 → 导出 / 复制”，在新电脑的“输入恢复”中粘贴代码即可。此功能迁移画师档案、对应成就和订阅记录，签到、下载文件及续传断点需要分别保留，软件不会自动同步。

### 为什么没看到版本更新入口？

页脚只在发现比当前版本更新、且没有被忽略的正式发布版时显示入口。网络检查失败会静默结束；也可以直接打开项目的 Releases 页面确认版本。

### 如何反馈问题？

请在 Issue 中提供 Windows 版本、软件版本、链接类型、错误文字以及复现步骤。分享日志或截图前，请遮去设备码、邀请码及个人信息。
