# Pawchive Downloader · Windows 使用说明

这是一份面向普通 Windows 用户的使用指南。它介绍安装、首次验证、下载、队列、后台运行、奖励和故障处理，不包含发布者私钥或管理员本机操作。

## 系统要求

- Windows 10 或更高版本
- 64 位处理器和系统
- 可访问 Pawchive 的网络环境
- 选择一个拥有写入权限的图片保存目录

软件以独立 EXE 发布，不要求安装 Python。

## 安装与首次验证

从 GitHub Releases 下载 `PawchiveDownloader-Windows-x64.exe`，将它放到普通文件夹后双击启动。

首次启动时：

1. 点击“复制设备码”。
2. 将设备码提供给软件发布者。
3. 粘贴收到的邀请码。
4. 点击“验证并进入”。

复制按钮会出现缩小回弹动画，并短暂显示“已复制”。验证成功后，邀请码会保存在本机，之后启动无需重复输入。

## 下载一个画师

在“画师主页链接”输入完整地址，例如：

```text
https://pawchive.pw/fanbox/user/3439325
```

选择保存目录后点击“开始下载”。默认会扫描该画师的图集并下载可用的原图和帖子附件。

可以在下载前设置：

- 按图集标题建立独立文件夹
- 从新到旧或从旧到新排序
- 先扫描标题并手动选择图集
- 平铺保存时按日期顺序编号

## 链接输入方式

支持三种方式：

- 在输入框粘贴画师主页链接
- 将画师主页链接拖入窗口
- 将帖子链接粘贴或拖入窗口

帖子链接会自动提取所属画师。软件会询问你下载该画师的可选图集，还是只下载当前帖子。

## 队列操作

批量下载时，右侧队列会显示每个图集的封面、标题、进度和状态。

单个项目可以：

- 暂停
- 继续
- 取消
- 重试

队列支持拖动调整优先级，也支持框选多个项目后置顶。图片最多五路并发，非图片附件保持单路下载。下载失败的项目会自动暂停并让位给后续任务；重试后会移动到最高优先级。

## 回收站

取消的下载会进入回收站，保留约 24 小时。回收站项目包含封面、标题、帖子链接和恢复按钮。

打开方式：点击右侧下载队列标题栏的回收站图标。

## 剪贴板和托盘通知

软件在后台运行时会检测剪贴板中的 Pawchive 画师链接。同一链接在一次启动期间只提醒一次，且通知之间有冷却时间。

下载完成后，托盘会显示完成提示。窗口右上角 `×` 默认只隐藏窗口，下载会继续；完全退出需要在托盘图标上右键选择“退出软件”。

## 签到与画师档案卡

“签到日历”提供累计签到、连续签到、徽章、画师图鉴、成就和主题皮肤。

达到 7 天连续签到可以解锁徽章，达到 30 天连续签到可以解锁海蓝和赛博朋克主题。

同一画师完成 25 个图集后会达到最高成就，并生成画师档案卡。档案卡可以从主界面顶部的 `✦` 按钮打开，包含画师头像、成就和本地下载统计。

## 自定义背景

背景编辑器支持 JPG、JPEG、PNG 和 WEBP。你可以为不同页面分别保存背景，拖动裁剪框选择起始坐标，并用滑块调整深色遮罩。

背景图片会经过尺寸和像素限制检查。软件只为当前页面加载预览图，避免多个大图同时占用内存。

手机图标切换竖屏模式，电脑图标恢复普通窗口模式。

## 缓存清理

点击扫帚按钮可以清理扫描临时目录、未使用背景缩略图、中断临时文件和未引用头像缓存。

软件不会删除下载目录、已完成图片或 `.part` 续传文件。

## 数据位置

用户数据默认位于：

```text
%LOCALAPPDATA%\PawchiveDownloader
```

这些数据包含签到、日程、断点、回收站、背景和档案卡缓存。它们只保存在当前电脑上，不会自动同步到其他设备。

## 反馈问题

提交问题时请说明：

- Windows 版本
- 软件版本
- 使用的链接类型（主页或帖子）
- 队列中显示的错误信息
- 是否可以稳定复现

不要在公开 Issue 中提交设备码、邀请码、下载目录截图或本机数据库文件。
