# Pawchive Downloader · Windows

这是 Pawchive Downloader 的 Windows 桌面版说明。Windows 版面向长时间下载和后台运行场景，数据、签到奖励、主题、背景编辑、断点和回收站都保存在当前 Windows 用户的本机应用数据目录中。

## 启动与首次使用

运行 `PawchiveDownloader.exe` 后，首次启动会显示设备码和邀请码窗口。点击“复制设备码”会将设备码写入剪贴板，按钮会短暂显示“已复制”，按下时会缩小并回弹，便于确认操作已经生效。把设备码交给发布者，粘贴收到的设备专属邀请码并验证即可。邀请码验证是离线签名校验；设备码、邀请码和下载记录不会上传到 Pawchive 服务。

验证通过后，输入完整的画师主页地址，例如 `https://pawchive.pw/fanbox/user/3439325`，选择保存目录，再点击“开始下载”。输入框支持粘贴、拖拽画师主页链接，也支持拖入某个帖子链接；帖子链接会自动提取所属画师并询问下载整个画师的可选图集，还是只下载当前图集。

## 下载工作台

- 可选择按标题分别建文件夹，或关闭分文件夹并按发布日期给文件编号。
- 选择“先扫描标题并选择下载图集”后，封面、标题、附件格式和链接会在选择窗口中列出；扫描可以暂停、继续或提前结束。
- 批量下载会出现在右侧队列。每张卡片包含图集缩略图、标题、百分比、当前状态和暂停/继续/取消/重试操作。
- 图片下载最多五路并发；ZIP、PSD、视频等非图片直链始终单路下载，并在失败重试之间加入间隔，降低触发网站限制的概率。
- 队列支持拖动调整优先级，也可用框选后点击置顶。下载开始后已经确定的序号顺序会保留，改变优先级不会打乱按日期编号。
- 暂停、取消或连续失败的图集会让位给下一项。失败项显示感叹号，点击重试会提升到最高优先级。
- 取消的图集会进入回收站，保留标题、封面、帖子链接和恢复入口。回收站按真实时间计算，默认保存约 24 小时；下次启动时也会继续清理过期内容。

右上角扫帚按钮只清理 Pawchive 自己产生的临时缓存、过期预览、未使用的背景缩略图和中断留下的安全临时目录，不会递归删除用户下载目录，也不会删除下载中的 `.part` 续传文件。回收站可从下载队列标题栏的回收图标打开。

## 剪贴板、托盘和拖拽

启用托盘后，软件每 1.5 秒检查一次剪贴板。复制新的 Pawchive 画师链接时，托盘会提示“主人，检测到新图集，要直接开始下载吗？”。相同链接在本次启动期间只提示一次，提示之间有冷却时间，不会因网页脚本刷屏。下载在后台完成时会提示“主人，你的图集下载好了哦～”。

点击窗口右上角 `×` 会直接隐藏到托盘，当前任务继续运行，不再弹出“这次，想如何离开”的选择框。需要完全退出时，在托盘图标上点击右键，选择“退出软件”；退出前会保存可续传的进度。没有系统托盘时，软件会回退为正常退出。

## 签到、等级、徽章和画师档案卡

工具菜单中的“签到日历”会记录当天签到，并根据累计签到、最长连续签到和下载数量计算奖励。奖励数据由本机 SQLite 状态库派生，不需要迁移旧版本数据库。

- 7 天连续签到解锁连续签到徽章；30 天连续签到解锁海蓝和赛博朋克主题皮肤。
- “画师图鉴”按签到和下载数量解锁；“成就彩蛋”记录首次回访、连续签到和下载里程碑。
- 每位画师也有独立的本地成就进度：完成 1、5、10、25 个图集分别达到初见、收藏、策展和最高成就“典藏画师”。
- 达到某位画师的最高成就后，软件从该画师的 Pawchive 头像地址取得头像，保存为受大小限制的本地缓存，并生成档案卡。顶部的 `✦` 按钮可打开“画师档案卡”柜，显示头像、画师标识、最高成就以及图集/文件数量。
- 头像只接受 Pawchive 允许的画师地址和图片响应，单张不超过 4 MB；获取失败不会影响下载，档案卡仍会保留并显示头像不可用。

## 自定义背景和竖屏模式

背景设置支持每个界面单独配置：工作台、签到日历、日程、邀请码、图集选择、扫描和续传窗口都可以分别设置。编辑器允许在原图上拖动和缩放裁剪框，保存归一化坐标 JSON 和最多 2048 像素的预览图。运行时只加载当前页面的预览，旧页面会释放到有界缓存池。

支持 JPG、JPEG、PNG、WEBP；原图最多 20 MB、最多 2400 万像素、单边最多 10000 像素。背景与控件之间有深色遮罩，可在主界面滑块调节深度。自定义背景和签到主题有独立开关，换回默认主题时不会丢失已保存的裁剪设置。

顶部手机图标用于切换竖屏模式。切换后主区自动使用 `QBoxLayout` 堆叠，窗口适度变窄并拉高；再次点击电脑图标即可恢复宽屏布局。高纵横比背景会保持比例，超出部分裁剪或由深色边缘填充。

## 日程、续传和本机清理

日程最多保存 10 项，Windows 任务计划程序负责唤醒；电脑关机期间错过的时间不会补跑。下载检查点保存在本机 SQLite 中，已完成文件不会被清理，未完成分片只允许位于本次下载目录内，路径会校验符号链接和目录越界。

发布者专用清理工具位于 `PawchivePublisherCleanup\\PawchivePublisherCleanup.cmd`。建议先运行：

```powershell
PawchivePublisherCleanup.cmd -Preview
```

预览会列出当前用户的应用数据、背景设置、过期 Pawchive 临时缓存和计划任务，不会修改文件。确认无误后运行不带 `-Preview` 的命令，并输入 `CLEAN`；无人值守场景可使用 `-Force`。追加 `-RemoveRegistry` 才会清除 Qt 默认路径设置。清理工具会先拒绝仍在运行的 Pawchive 进程，并跳过重解析点，不触碰用户下载目录、`.part` 文件或邀请码签发私钥。

## 本机文件位置

默认数据目录为：

```text
%LOCALAPPDATA%\\PawchiveDownloader
```

其中包含状态数据库、下载断点、日程、签到奖励、回收站、背景 JSON/预览和画师头像缓存。发布前可用清理工具删除这些发布者足迹；用户下载目录需要由用户自行保留。

## 构建 Windows EXE

需要 64 位 Windows 和 64 位 Python。建议在 `windows` 目录创建隔离环境，然后安装锁定依赖：

```powershell
py -3.14 -m venv .venv
.\\.venv\\Scripts\\python.exe -m pip install -r requirements-build.txt
.\\.venv\\Scripts\\python.exe build_release.py
```

`build_release.py` 会执行以下检查：验证依赖版本、检查 Qt 对 Windows 系统 ICU 的导入、清理 PyInstaller 构建目录、生成 `dist\\PawchiveDownloader.exe`，然后在无窗口 Qt 环境启动一次冻结程序。启动检查必须通过且不能产生 stderr 才能发布。构建脚本会过滤系统 ICU DLL，避免把第三方原生库意外带入包中。

发布包应同时提供 `PawchiveDownloader.exe`、`1.ico`、`activation_public.json`、`PawchivePublisherCleanup` 目录、`THIRD_PARTY_NOTICES.md` 和本说明。邀请码生成器及其私钥只放在发布者自己的受控目录，不能随 Windows 客户端一起分发。

## 运行验证

无需 Qt 的状态和安全测试可以直接运行：

```powershell
python -m unittest discover -s tests -p "test_*.py"
```

如果没有安装 PySide6，Qt UI 测试会被跳过或无法导入；这不影响纯 Python 的状态、链接、缓存、断点、回收站和计划任务安全测试。发布前应在构建隔离环境中运行完整测试，并执行上面的冻结启动检查。

本次 Windows 收尾版本不自动上传 GitHub；发布者可在确认 EXE 启动、首次邀请码验证、托盘退出、队列恢复和清理工具预览结果后再上传。
