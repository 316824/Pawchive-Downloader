# Pawchive Downloader · Windows 界面预览

本地设计分支：`design/windows-ui-refresh`。默认窗口为 1180 × 941，会根据屏幕可用区域调整；缩小后两侧工作区独立滚动。

## 新界面

- 左侧设置画师链接、保存位置、日期顺序与保存方式；右侧固定呈现任务进度和日志。
- 顶部阶段条对应设置、预选、下载和完成，错误与停止也有独立状态。
- 大号百分比代表**当前文件进度**；图集序号、实时传输速度和已保存文件数分别显示。
- 封面预选支持标题搜索和已选数量，筛选不会取消已经选中的图集。
- 日志可收起，复制日志后仍保留下载完成时的“打开文件夹”。
- 矢量太阳、月亮、下拉箭头和工具按钮，适应明暗主题与缩放。

鼠标移动和点击粒子、按钮延迟高亮、复选框渐变光效、彩虹进度条、主题滑钮、扫描动画，以及署名单字弹跳与烟花彩蛋继续保留。

## 快捷操作

| 操作 | 入口 |
| --- | --- |
| 粘贴画师主页链接 | 输入框右侧按钮；`Ctrl+Shift+V` |
| 开始任务 | 开始下载；`Ctrl+Enter` |
| 显示／收起日志 | 顶部眼睛按钮；`Ctrl+L` |
| 停止下载 | 运行时的“停止下载”按钮 |
| 搜索预选图集 | 预选窗口的搜索栏 |

停止下载沿用原有清理规则：删除此次任务新建且尚未完成的图集文件夹，保留已完成的图集；已有目录不作整目录删除。网络请求结束可能需要等待其超时。

## 检查与构建

在本目录的独立虚拟环境中运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tools\render_design.py
.\.venv\Scripts\python.exe build_release.py
```

预览截图位于 `build/ui-preview/`。运行状态截图使用本地模拟数据，并注明“离线界面示例”；检查过程不访问网站、不下载实际图集。

设计参考了 [Linear](https://linear.app/features) 的信息层级与 [Raycast](https://www.raycast.com/) 的快捷操作方式。程序继续使用项目原有图标与署名。
